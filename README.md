Panadería Jumbo
Sistema web para la gestión y consulta de fichas técnicas de panadería de Jumbo.
Demo
https://fichas-panader-a.onrender.com
Funcionalidades

Login con verificación en dos pasos por correo
Buscador de fichas técnicas
Calculadora de cantidades según harina deseada
Detalle completo de cada ficha (materias primas, horneado, envases, formatos de venta)
Registro de usuarios
Panel de administración

Tecnologías

Django 5.2
Django REST Framework
PostgreSQL (producción)
SQLite (desarrollo)
Cloudinary (imágenes)
Bootstrap 5
Render (hosting)
